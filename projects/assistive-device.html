NeuroLens: Emotion Recognition Assistant

A low-cost assistive tool that reads the facial expression of the person in front of the user and shows the detected emotion in real time. The Raspberry Pi Zero 2W and its camera are a fully standalone system: all of the computer vision runs on the Pi itself, and the results are streamed live over WebSockets.

  • Raspberry Pi Zero 2W
  • Arducam v3 (IMX708)
  • Python
  • OpenCV (Haar cascades)
  • FER-2013
  • WebSockets
  • HTML/CSS/JS

The problem

About 1 in 127 people are autistic (WHO), and many find it hard to read nonverbal cues like facial expressions, which can make social situations stressful. NeuroLens is designed as a socio-emotional learning (SEL) aid for children 6 and up: a tool for practising emotion recognition in class or role-play, and for checking in during real conversations.

My role

  • Led the engineering team through requirements, system design, prototyping, and testing.
  • Designed the Python system architecture around computer vision and WebSockets.
  • Guided teammates in deploying ML models on the Raspberry Pi for real-time camera inference.

How it works

┌──────────── Raspberry Pi Zero 2W (standalone) ────────────┐
│ Arducam v3 → Haar face detection → CNN emotion classifier │ ──WebSocket──▶ web app (any browser)
└───────────────────────────────────────────────────────────┘

Everything runs on the Pi. The Pi and camera work as their own self-contained device: capture, face detection, and emotion classification all happen on the Pi Zero 2W, with no laptop, cloud server, or external GPU doing the processing. The Pi only sends out the results, streaming them over WebSockets to the web app, which just displays them.

  1. Capture: the Arducam v3's high image quality gives clear facial input to the Raspberry Pi Zero 2W.
  2. Face detection: OpenCV Haar cascades find each face in the frame.
  3. Emotion recognition: the face is cropped and classified into one of seven emotions (angry, disgust, fear, happy, neutral, sad, surprise) by a compact CNN I trained on FER-2013.
  4. Live output: the Pi runs a WebSocket server and the web app is the client, so each result is pushed to the app as soon as it's recognised. The app shows the top emotion with its confidence, plus the other likely emotions.

Making the model light enough for a Pi Zero

A Pi Zero 2W has very little processing power, so every part of the pipeline was chosen to keep output real-time:

  • A small CNN trained on FER-2013. I designed a compact network for 48×48 grayscale faces: three convolution blocks (16, 32, and 64 filters, each with batch normalization and max pooling), then one 64-unit dense layer with dropout and a 7-way softmax. It has about 172,000 parameters in total. I trained it for 25 epochs on FER-2013's labelled faces.
  • Quantized export. Converting to TensorFlow Lite with default optimization shrank the model to about 178 KB.
  • No ML framework on the Pi. The server runs the trained network in plain NumPy: I exported the weights and wrote the forward pass (convolution, batch norm, ReLU, pooling, dense layers, and softmax) by hand, so the Pi only needs NumPy and OpenCV.
  • Cheaper face detection. Haar cascades run on a frame downscaled to 320×240, and the face coordinates are scaled back up to crop from the full 640×480 frame.
  • Non-blocking server. Detection runs in a background thread, so the WebSocket server stays responsive while the Pi processes each frame.

Design decisions

  • Processor: Raspberry Pi Zero 2W, not an ESP32 or a full Pi. A full-size Pi is too big to wear. The ESP32's single-core 32-bit processor is limited to light, specialized models and can't keep up with real-time video, and the ESP32-CAM's image quality is too low for subtle facial features. The Pi Zero 2W's quad-core 64-bit processor fits the size budget and can run inference on live video.
  • Camera: Arducam v3 with a 12 MP IMX708 sensor. Emotions show in small details around the eyes and mouth, so image quality mattered. Autofocus keeps the face sharp as distance changes.
  • WebSockets, not HTTP polling. Repeated HTTPS requests added too much latency for a live conversation. A WebSocket lets the Pi push each result as soon as it's ready.
  • A web app, not a mobile app. A browser-based display gave faster access to a continuous stream of results, with nothing to install.

Challenges

  • Limited processing power. Running face detection and emotion classification on a Pi Zero 2W in real time was the main constraint. I handled it with the compact model, the plain-NumPy inference, and downscaled face detection described above.
  • Poor lighting. Accuracy dropped in dim or uneven light. To help, each face crop is contrast-equalized with CLAHE (adaptive histogram equalization) before classification, a slightly padded crop gives the model the full face, and the camera runs with auto exposure and auto white balance.

Applications

  • SEL classroom tool: helps children learn and recognize basic emotions.
  • Classroom game: children try to read the emotion someone else is conveying, then check whether they were right.
  • Self-expression practice: autistic people often find it hard to tell what emotions their own face is conveying. NeuroLens can show which expression they're making and the emotion it's usually read as.

Next steps

  • Better accuracy in hard conditions: retrain with more varied data (different lighting and angles), train longer, and add augmentation such as flips, rotations, and brightness shifts, so the model holds up on a head-mounted camera.
  • Body language: add pose estimation (e.g. OpenPose) and a second classifier, and combine it with the facial result for the final emotion.
  • Wearable form factor: package the Pi and camera into a module that attaches to the side of any pair of glasses.
